Standardized Notes.md Template

Every problem folder should have a Notes.md adhering strictly to this concise 3-part layout:

# [Problem Name] — [Difficulty]

### 1. Invariant Trigger
* **Signal:** (e.g., "Finding min cost on DAG with edge weights >= 0 -> Dijkstra")
* **Core Invariant:** (e.g., "Queue stores [cost, node]; discard polled entries where cost > dist[u]")

### 2. Failure Traps & Edge Cases
* Subtraction in comparator `(a, b) -> a - b` risks 32-bit integer overflow; always use `Integer.compare()`.
* Boundary: Check $k = 0$, single-node graphs, and disconnected components.

### 3. Complexity & Variations
* **Time:** $O((V + E) \log V)$
* **Space:** $O(V + E)$
* **Google Follow-up:** "What if the graph cannot fit in memory?" -> Partition adjacency across external shards using vertex IDs.
